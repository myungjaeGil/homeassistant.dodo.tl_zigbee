# xmasTree — ZT3L 크리스마스 트리 3채널 전등

ZT3L(TLSR8258)로 트리 전구 3줄을 각각 PWM 디밍하고, 물결·추적·반짝임 같은 효과를 돌리는 Zigbee 펌웨어입니다. PWM5CH 수정본을 바탕으로 만들었고, 아래 처리는 PWM5CH와 같습니다.

- 감마 보정과 출력단 프리셋 (`PWM_HW_TYPE`)
- 채널별 디밍 구간(20~80%)
- 페이드, NV 저장, IR, OLED
- 조인 재시도, OTA

## 배선 (PWM5CH 보드 그대로 사용)

| 트리 채널 | ZT3L 핀 | GPIO | PWM5CH 보드 출력 |
|---|---|---|---|
| CH1 | Pin 7  | PC2 (PWM0) | CH0 |
| CH2 | Pin 6  | PC3 (PWM1) | CH1 |
| CH3 | Pin 13 | PB4 (PWM4) | CH4 |
| 미사용 | Pin 5 / Pin 14 | PD2 / PB5 | CH2 / CH3 (LOW 고정) |

- PD2(Pin5)는 옆 핀 PD7(디버그 TX)과 간섭한 적이 있어서 비워 두었습니다.
- 다른 출력을 쓰려면 `board_8258_zt3l.h`의 `PWM_CHx_*` 정의를 바꾸면 됩니다.
- 전구는 단색 LED 줄 3개를 기준으로 했습니다. 2선식 교차 극성 전구(한 줄 안에서 극성을 바꿔 두 색을 번갈아 켜는 방식)는 H브리지가 필요하므로 이 보드로는 구동할 수 없습니다.

## 효과

| 번호 | Z2M 값 | 동작 |
|---|---|---|
| 0 | `steady` | 상시 점등 (채널별 밝기 그대로) |
| 1 | `waves` | 물결 — 세 줄이 120°씩 어긋나게 밝아졌다 어두워짐 (첫 부팅 기본값) |
| 2 | `sequential` | 순차 점등 — 1 → 1+2 → 1+2+3 → 꺼짐 |
| 3 | `glow` | 숨쉬기 — 세 줄 동시에 천천히 |
| 4 | `chase` | 추적 — 한 줄씩 돌아가며 |
| 5 | `crossfade` | 교차 페이드 — 한 줄이 꺼지면서 다음 줄이 켜짐 |
| 6 | `twinkle` | 반짝임 — 줄마다 무작위 |
| 7 | `flash` | 동시 점멸 |
| 8 | `alternate` | 교대 점멸 — CH1·CH3 ↔ CH2 |
| 9 | `auto` | 1~8 을 `auto_interval` 초마다 차례로 교체 |

- **속도:** 1~10 단계이며, 기본값 5는 한 주기 2초입니다. 1은 8초, 10은 0.55초입니다.
- **효과가 도는 조건:** 전체(EP4)가 ON이고 효과가 `steady`가 아닐 때만 돕니다.
- **채널 ON/OFF와 밝기:** 효과 중 채널을 끄면 그 줄은 효과에서 빠지고, 채널 밝기는 그 줄의 최대 밝기가 됩니다.
- **효과를 끌 때:** `steady`로 바꾸면 그 자리에서 원래 밝기로 1초 동안 부드럽게 돌아갑니다.
- **저장:** 효과, 속도, 자동 순환 간격은 마지막 변경 2초 뒤 NV에 저장되어 재부팅 후에도 유지됩니다.

## Zigbee

| EP | 클러스터 | 내용 |
|---|---|---|
| 1~3 | OnOff + Level | 트리 CH1~CH3 |
| 1~3 | Level 0xF000 / 0xF001 | 디밍 구간 min/max % (PWM5CH와 동일) |
| 4 | OnOff + Level | 전체 전원·밝기 |
| 4 | OnOff 0xF000 | 효과 0~9 (enum8, R/W, 리포트) |
| 4 | OnOff 0xF001 | 속도 1~10 (uint8, R/W, 리포트) |
| 4 | OnOff 0xF002 | 자동 순환 간격 5~3600초 (uint16, R/W) |
| 4 | OnOff 0xF003 | 실제 동작 중인 효과 (enum8, 읽기·리포트) |

- 모델 ID는 `ZT3L-XMAS3CH`, 제조사는 `DODO`입니다.
- OTA 이미지 타입은 `0x58`('X')입니다.
- NV 항목은 0x40~0x45로, PWM5CH와 겹치지 않습니다.

PWM5CH 펌웨어를 쓰던 보드에 올릴 때:

1. 모델 ID가 바뀌므로 BUTTON1을 5초 눌러 공장 초기화합니다.
2. 다시 페어링합니다.

## 로컬 조작

**BUTTON1**

| 누름 | 동작 |
|---|---|
| 짧게 (1초 미만) | 다음 효과 |
| 5초 | 공장 초기화 |

**IR (NEC)** — PWM5CH 리모컨 배치를 그대로 씁니다.

| 버튼 | 동작 | 버튼 | 동작 | 버튼 | 동작 |
|---|---|---|---|---|---|
| 0x45 | 전체 ON | 0x47 | 전체 OFF | | |
| 0x44 | CH1 토글 | 0x40 | CH1 UP | 0x43 | CH1 DN |
| 0x07 | CH2 토글 | 0x15 | CH2 UP | 0x09 | CH2 DN |
| 0x16 | CH3 토글 | 0x19 | CH3 UP | 0x0D | CH3 DN |
| 0x0C | 다음 효과 | 0x18 | 속도 UP | 0x5E | 속도 DN |
| 0x08 | 이전 효과 | 0x1C | 상시 점등 | 0x5A | 자동 순환 |
| 0x42 | 전체 토글 | 0x52 | 전체 밝기 UP | 0x4A | 전체 밝기 DN |

**OLED** — 4줄로 표시합니다.

1. Zigbee 상태
2. CH1~CH3 밝기
3. 전체 밝기, 속도, 효과 (자동 순환일 때는 `A>현재효과`)
4. 최근 IR 입력

## 설정 — `app_cfg.h`

| 항목 | 기본값 | 설명 |
|---|---|---|
| `XMAS_FX_DEFAULT` | 1 | 첫 부팅 효과 (물결) |
| `XMAS_FX_SPEED_DEFAULT` | 5 | 첫 부팅 속도 |
| `XMAS_FX_AUTO_SEC_DEFAULT` | 30 | 첫 부팅 자동 순환 간격 |
| `XMAS_FX_TICK_MS` | 20 | 효과 갱신 주기 |
| `XMAS_BUTTON_FX_ENABLE` | 1 | 버튼 짧게 = 다음 효과 |
| `DEBUG_ENABLE` | 1 | 디버그 로그 (PD7) |

첫 부팅(NV 없음)에는 CH1~CH3와 전체 전원이 모두 ON 상태로 시작합니다.

## SDK 쪽 작업

PWM5CH와 같습니다.

- **IR 연결:** `irq_handler.c`의 IR 연결은 `ir_irq_patch.txt`를 참고하세요.
- **새 프로젝트 추가:** SDK `apps/` 아래에 이 폴더를 새 프로젝트로 추가합니다. 빌드 설정은 PWM5CH 것을 복사하고 소스 목록만 이 폴더 파일로 바꿉니다. 새로 생긴 소스는 `xmas_fx.c`입니다.

## Z2M

1. `ZT3L-XMAS3CH.js`를 `data/external_converters/`에 넣고 Z2M을 재시작합니다.
2. 이미 페어링된 장치라면 **Reconfigure**를 한 번 누릅니다.

HA에는 다음 항목이 생깁니다.

- 조명: CH1·CH2·CH3·전체 4개
- 효과 선택, 실제 동작 효과 센서
- 효과 속도
- 자동 순환 간격, 채널별 디밍 구간 (설정 항목)
